# Character art

The app prefers a **cartoon medallion** per character, then the layered PNG set,
then the drawn sigil.

## Preferred: cartoon medallion

```
<persona-id>/
  cartoon.png   1024×1024 RGBA, soft circular medallion, 3D-cartoon portrait
  face.json     normalized mouth and eye rects for the jaw puppet
```

`face.json` is written by `scripts/face-landmarks.swift` from Vision face
landmarks. If it is missing, the app falls back to a generic layout.

The medallion is deliberate: the generated portrait keeps its own painted
background, and a soft elliptical mask blends it into the paper stage. There is
no fragile cutout edge to clean up.

### Regenerating the cartoon set

```
make cartoon                 # all missing characters, one request per ~70 s
make cartoon FORCE=1         # re-download everything
```

The script uses the free Pollinations classic endpoint (768 px, small logo
cropped, ~45 s per request). It pads the frame, asks Vision for the face
landmarks, applies the medallion mask, and adds a soft shadow. Replace
`cartoon.png` with final art at any time; rerun
`scripts/face-landmarks.swift` if the face moves.

Style direction: stylized 3D animated family film, cinematic soft light,
rounded appealing shapes, expressive eyes, bust portrait, medallion framing.
Avoid flat vector/doodle styles.

## Fallback: layered PNGs

```
  base.png           mouth closed, eyes open
  mouth-small.png    same frame, only the mouth differs
  mouth-medium.png
  mouth-wide.png
  eyes-closed.png    same frame, transparent except the eye region
```

These are generated by `scripts/make-placeholder-art.py` (`make art`). They are
flat vector stand-ins, not final art.

Persona ids: `silas`, `morwenna`, `mortlake`, `azgorath`, `fennick`,
`vyrmathrax`, `grub`, `aldric`, `snowqueen`, `bramwell`, `godmother`, `thing`.

Run `make check-art` before shipping.
